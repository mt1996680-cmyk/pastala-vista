# Pasta La Vita — Official Restaurant Website

Wah Cantt's premier Italian bistro offering authentic homemade pastas, rich white & flaming red sauces, loaded sides, table reservations, and direct WhatsApp ordering.

## 🚀 How to Run & Use

### Option 1: Direct File Opening (No Installation Required)
Simply double-click **`index.html`** to open the website directly in any web browser (Google Chrome, Microsoft Edge, Safari, Firefox).

### Option 2: Run with Local Server (Recommended for Live Preview)
If you have Python or Node installed:
```bash
# Using Python
python -m http.server 8085

# Using Node.js
npx serve .
```
Then open `http://localhost:8085` in your browser.

## 📱 Features Included
- **Dynamic Hours Indicator:** Checks Pakistan Standard Time (PKT) and displays "Open Now · Closes 10:30 PM" or "Closed · Opens 11:00 AM".
- **Interactive Menu:** Filter by category (White Sauce, Red Sauce, Fries, Combos, Drinks) or search dishes by keyword.
- **Cart & Direct WhatsApp Checkout:** Itemized orders formatted automatically and sent to `0300 1501945` via WhatsApp.
- **Table Reservation Modal:** Dine-in and VIP private room booking.
- **Google Reviews (4.8★):** Authentic customer reviews and Google Maps link.
- **Location & Delivery Map:** Main GT Road, opposite New City Phase-II & Mall of Wah Food Court.
